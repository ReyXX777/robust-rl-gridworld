# robust-rl-gridworld
A reinforcement learning framework designed to handle multiple training distributions while detecting and adapting to out-of-distribution states. Agents learn conservative policies when encountering unfamiliar scenarios, improving robustness and safe decision-making.
Robust Distribution Reinforcement Learning Framework
The Robust Distribution Reinforcement Learning Framework provides a simulation environment designed to test agent resilience against shifting data distributions. It focuses on the intersection of goal directed navigation and risk awareness within a grid world setting.

Environment Overview
The environment consists of a discrete grid where an agent must collect a specific number of goals. During each episode, the system selects a unique probability distribution that defines which areas are considered "in-distribution" for the agent. Any movement into a cell with low or zero probability according to the active distribution is flagged as an Out-of-Distribution (OOD) event. The agent receives a small negative reward for every step taken to encourage efficiency while a large positive reward is granted upon reaching a goal location.

Robust Q-Learning Algorithm
The learning process employs an off-policy Q-learning approach modified for distribution awareness. Unlike standard reinforcement learning, the temporal difference update integrates a robustness factor. If the agent transitions into an OOD state, the value of future rewards is discounted more heavily.
The robustness weight $W_{ood}$ acts as a safety parameter. It ensures that the agent learns to prefer paths that remain within the known distribution unless the reward for straying is high enough to justify the risk. Action selection includes a random tie-breaking mechanism to prevent the agent from developing a bias toward specific directions during the early stages of training.Performance VisualizationThe script generates a multi-panel figure to track agent progress over thousands of episodes. The first plot illustrates the cumulative reward which indicates how well the agent is balancing goal collection with step costs. The second plot monitors the frequency of OOD steps to show if the agent is learning to stay within the safe bounds of the current distribution. The final plot tracks the average number of goals reached per episode to confirm successful task completion.
